Snapcast

The board joins Music Assistant as a Snapcast player and analyses the audio it receives. It plays nothing: snapclient hands the audio to the board's server instead of a sound card. Works with Music Assistant 2.7 and later.

auto uses the host of the Music Assistant server URL above, where its built-in Snapcast server runs.

Sendspin

Music Assistant streams live visualizer data to the board. The board joins as a display-only Sendspin client: it plays no audio and uses no microphone. It needs pip install -r requirements-sendspin.txt on the server (Python 3.12+, and the version must match Music Assistant's).

auto finds Music Assistant on the network. You can also enter ws://IP:8927/sendspin, or leave it empty to wait for Music Assistant to find the board.

Gamepad

Plug USB gamepads or a Mayflash GameCube adapter (PC mode) into the server to play the board's games. Each adapter port is a player, port 1 = player 1. The stick and D-pad steer, A and B are the game buttons. In Doom, L/R strafe, X switches weapon, Y toggles run, Z opens doors and Start pauses. In NES games, Z or X is Select, Y saves the game and L loads it.

Hold Start to open the game menu on the board: up and down choose, left and right change the category, A plays, B goes back to your game.
