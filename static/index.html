Music Assistant visualizer (Sendspin)

Lets Music Assistant stream live visualizer data (loudness, spectrum, beats) for what's playing to the board, so the Music visualizer app follows the actual music. The board joins as a display-only Sendspin client: it plays no audio and uses no microphone. Needs pip install -r requirements-sendspin.txt (Python 3.12+; the version must match Music Assistant's). Without it, the visualizer uses a generated beat.
